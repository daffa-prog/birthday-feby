WEBSITE ULANG TAHUN FEBY ❤️
===========================

CARA MENJALANKAN
1. Ekstrak file ZIP ke folder yang mudah ditemukan, misalnya Desktop.
2. Buka folder birthday-feby.
3. Klik kanan index.html > Open with > Google Chrome.
4. Klik kotak kado untuk membuka kejutan.
5. Tombol Music di kanan atas menampilkan pemutar YouTube JVKE - golden hour.
   Catatan: YouTube perlu koneksi internet dan pemutaran mungkin harus ditekan manual.

CARA MENGEDIT DI NOTEPAD++
1. Buka Notepad++.
2. Pilih File > Open, lalu buka index.html, style.css, dan script.js sesuai kebutuhan.
3. Setelah mengedit, tekan Ctrl+S lalu refresh Chrome.

CARA MEMASUKKAN FOTO
Foto utama:
- Simpan foto kamu dan Feby dengan nama: feby-kalian.jpg
- Masukkan ke folder images.
- Untuk galeri, masukkan foto dengan nama:
  kenangan-1.jpg
  kenangan-2.jpg
  kenangan-3.jpg
  kenangan-4.jpg

Gunakan format JPG/JPEG dan usahakan ukuran foto tidak terlalu besar.
Nama file harus sama persis dengan nama pada index.html. Jika ingin memakai nama lain,
ubah juga nama pada atribut src di index.html.

MENERBITKAN WEBSITE AGAR BISA DIBUKA LEWAT LINK (GITHUB PAGES)
1. Buat akun atau masuk di https://github.com/
2. Buat repository baru, misalnya birthday-feby.
3. Unggah index.html, style.css, script.js, folder images (termasuk foto yang ingin dipublikasikan),
   dan file lain yang diperlukan. Jangan unggah file pribadi yang tidak ingin dibagikan.
4. Buka Settings > Pages pada repository.
5. Pada bagian Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu Save.
7. Tunggu beberapa menit. GitHub akan menampilkan URL website di bagian Pages.
8. Buka URL itu untuk menguji, lalu kirim link kepada Feby.

PENTING TENTANG MUSIK
- Website memakai pemutar YouTube resmi yang di-embed dari video ID PEM0Vs8jf1w.
- Musik memerlukan internet. Browser dapat membatasi autoplay dengan suara; Feby mungkin perlu
  menekan tombol Play pada pemutar YouTube.
- Jangan mengunduh atau mengunggah ulang lagu berhak cipta tanpa izin.

FILE
- index.html : struktur dan isi halaman
- style.css  : warna, layout, desain responsif, animasi
- script.js  : buka kado, bunga, navigasi slide surat
- images/    : tempat foto-foto
- music/     : opsional, disediakan jika kelak memakai file audio sendiri
